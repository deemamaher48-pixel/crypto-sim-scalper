# Crypto Sim Scalper

بدي تطبيق لوحة تحكم تداول آلي وسكالبينغ (Crypto Scalping Dashboard) لـ Binance، مع واجهة عربية تعرض الشارت والأسعار المباشرة، وصفحة إعدادات آمنة لإدخال مفاتيح الـ API ودعم الـ Testnet، مع تحليلات ومؤشرات فنية (EMA و RSI)، وإدارة مخاطر صارمة لتحديد وقف الخسارة وجني الأرباح وحجم الصفقة، وسجل تفاعلي بالصفقات والأداء.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://crypto-sim-scalper.lovable.app
